История операций
Как завести кошелёк
  1. Поставь TronLink из App Store (официальный кошелёк сети Tron, где живёт USDT TRC20).
  2. Создай кошелёк → «Create Wallet». Это будет холодный кошелёк — основной сейф.
  3. Сохрани seed-фразу офлайн: 12 слов на бумагу, никому и никуда не вводи. Кто знает фразу — владеет деньгами.
  4. Заведи второй, «горячий» кошелёк (ещё раз Create Wallet) — только для бота. На нём держим оборотку, не весь баланс.
  5. Скопируй адрес горячего кошелька (начинается на T…) — его дадим боту и укажем в выплатах Playerok.
  6. Купи немного TRX (~20–50) — это «бензин» за переводы USDT. Без него перевод не уйдёт.
  7. Бесплатный ключ TronGrid (trongrid.io) — доступ бота к сети. Зарегайся, создай API Key.
  8. Приватный ключ горячего кошелька экспортируешь в TronLink и отдаёшь боту (на сервер, зашифрованным). Ключ холодного — никогда и никому.
⚠️ Переводы крипты необратимы. Поэтому у бота белый список адресов и лимиты, а на горячем кошельке — только оборотные деньги.
