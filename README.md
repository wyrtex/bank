# Казна

Личный крипто-кошелёк магазина для iPhone: баланс USDT, график движения средств, история, авто-оплата
поставщикам с лимитами и белым списком, вход по ключу доступа. Интерфейс — в `www/index.html`; в .ipa
его заворачивает Capacitor.

> ⚠️ **Секреты никогда не кладём в репозиторий.** Приватный ключ кошелька, токены, `.env` — только на
> сервере, зашифрованными. `.gitignore` уже исключает их. Репозиторий держи приватным.

## Как собрать .ipa (без своего Mac)

1. Залей этот репозиторий к себе (он уже здесь) и держи его **приватным**.
2. Открой вкладку **Actions** → workflow **«Build unsigned IPA»** → **Run workflow** (или просто запушь в `main`).
3. GitHub на macOS-раннере соберёт **неподписанный** `Kazna-unsigned.ipa` и положит в **Artifacts** внизу запуска.
4. Скачай `.ipa`, открой в **eSign**, подпиши своим сертификатом и установи на айфон.
5. Обновление: меняешь `www/index.html` → новый запуск Actions → новый `.ipa` → переподписываешь в eSign.
   Данные между переустановками не теряются — состояние на сервере, вход по ключу доступа.

Локально (если есть Mac с Xcode): `npm install` → `npx cap add ios` → `npx cap open ios`.

## Как завести кошелёк (USDT TRC20, сеть Tron)

1. Поставь **TronLink** из App Store.
2. Создай кошелёк (**Create Wallet**) — это **холодный** кошелёк, основной сейф.
3. Сохрани seed-фразу (12 слов) **офлайн на бумаге**. Никому и никуда не вводи — кто знает фразу, владеет деньгами.
4. Создай **второй, «горячий» кошелёк** — только для бота. На нём держим оборотку, не весь баланс.
5. Скопируй **адрес** горячего (начинается на `T…`) — его дадим боту и укажем в выплатах Playerok (USDT TRC20).
6. Купи немного **TRX** (~20–50) — это «бензин» за переводы USDT.
7. Заведи бесплатный **API Key на trongrid.io** — доступ бота к сети Tron.
8. **Приватный ключ горячего** кошелька экспортируй в TronLink и отдай боту (на сервер, зашифрованным).
   Ключ **холодного** — никогда и никому.

Переводы крипты необратимы, поэтому у бота — белый список адресов и лимиты, а на горячем кошельке только
оборотные деньги.
